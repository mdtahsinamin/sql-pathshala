# SQL পাঠশালা · SQL Pathshala

বাংলা ও ইংরেজিতে ইন্টারঅ্যাকটিভ SQL শেখার ওয়েব অ্যাপ — ব্রাউজারেই আসল SQLite ডেটাবেসে কুয়েরি চালানো যায়। কোনো সার্ভার বা ব্যাকএন্ড লাগে না।

## চালানোর নিয়ম

```bash
python -m http.server 8000
# ব্রাউজারে: http://localhost:8000
```

`index.html` সরাসরি ডাবল-ক্লিক করে খুললেও চলে, তবে অফলাইন মোড (PWA) ও "অ্যাপ ইনস্টল" শুধু `http://` দিয়ে চালালে কাজ করে। প্রথমবার ইন্টারনেট লাগে (লাইব্রেরি CDN থেকে আসে), তারপর ক্যাশ থেকে অফলাইনেও চলে।

যেকোনো স্ট্যাটিক হোস্টিংয়ে (GitHub Pages, Netlify, Vercel) ফোল্ডারটি আপলোড করলেই ওয়েবসাইট তৈরি।

## AI টিউটর ও API key

- console.anthropic.com থেকে key নিয়ে টিউটরের ⚙ সেটিংসে দাও। key শুধু ওই ব্রাউজারের localStorage-এ থাকে এবং সরাসরি `api.anthropic.com`-এ যায়।
- ডিফল্ট মডেল Claude Opus 5.5; সেটিংস থেকে Sonnet 5.5 বা কম খরচের Haiku 5.5 বেছে নেওয়া যায়। প্রতিটি প্রশ্নের খরচ key-এর মালিকের অ্যাকাউন্টে যায়।
- পাবলিক ওয়েবসাইটে নিজের key বসিয়ে দেবে না — প্রত্যেক ইউজার নিজের key দেবে। সবার জন্য ফ্রি AI দিতে চাইলে একটি ছোট ব্যাকএন্ড প্রক্সি লাগবে।

## সবার জন্য ফ্রি AI (ঐচ্ছিক)

`server/ai-proxy-worker.js` একটি Cloudflare Worker — তোমার API key সার্ভারে গোপন রাখে, শুধু তোমার সাইটের অনুরোধ নেয়, মডেল/টোকেন সীমিত রাখে আর প্রতি IP-কে দিনে নির্দিষ্ট সংখ্যক প্রশ্ন দেয়। ফাইলের শুরুতে ডিপ্লয়ের ধাপ লেখা আছে। ডিপ্লয়ের পর URL-টা `js/config.js`-এর `aiProxy`-তে বসালে ব্যবহারকারীদের key লাগবে না (খরচ তোমার অ্যাকাউন্টে)। ইউজার চাইলে টিউটরের ⚙ সেটিংসে নিজের key বা proxy URL-ও দিতে পারে।

## নতুন কনটেন্ট যোগ করা

```js
// লেসনে অনুশীলন (js/lessons.js)
{ task: 'প্রশ্ন', solution: 'SELECT ...;', hint: '...', ordered: true }
// DML/DDL: check কুয়েরি দিয়ে ফলাফল মেলানো হয়
{ task: '...', solution: 'UPDATE ...;', check: 'SELECT * FROM t ORDER BY id;' }

// চাকরি প্রস্তুতি (js/jobprep.js) — type: 'sql' | 'mcq' | 'viva'
{ id: 'j-new', cat: 'nth', type: 'sql', level: 'easy', src: 'Exam name type',
  q: { bn: '...', en: '...' }, hints: [{ bn, en }], solution: '...', explain: { bn, en } }

// লেসনে ভিডিও: লেসন অবজেক্টে video: 'YouTubeVideoId'
```

উত্তর যাচাই হয় ইউজারের কুয়েরি ও সমাধান দুটোই নতুন ডেটাবেসে চালিয়ে ফলাফল (মান) মিলিয়ে — কলামের নাম বা লেখার ধরন আলাদা হলেও সঠিক উত্তর গ্রহণ করা হয়।
